# 🌤️ Laporan Cuaca

Website laporan cuaca real-time menggunakan Open-Meteo API. Cari cuaca kota mana pun di dunia.

## 🔗 Live Demo

**https://pmuhammadagus-byte.github.io/weather-report/**

## Fitur

- 📍 **Geolocation otomatis** — deteksi lokasi GPS saat buka website
- 🔍 Cari cuaca berdasarkan nama kota
- 🌡️ Suhu saat ini, kelembaban, kecepatan angin, tekanan udara
- 📅 Prakiraan 7 hari ke depan
- 📱 Responsive design (mobile-friendly)
- 🆓 Tanpa API key — gratis selamanya

## Teknologi

- HTML5, CSS3, JavaScript (vanilla)
- Open-Meteo API (geocoding + forecast)
- GitHub Pages (hosting)

## Cara Pakai

1. Buka [website](https://pmuhammadagus-byte.github.io/weather-report/)
2. Izinkan akses lokasi untuk deteksi otomatis, atau
3. Ketik nama kota (mis. Jakarta, Tokyo, London)
4. Tekan Enter atau klik "Cari"

## Deploy

Website ini di-deploy menggunakan GitHub Pages:

```
Settings → Pages → Source: main branch → /(root)
```
